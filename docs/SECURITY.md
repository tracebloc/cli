# Security policy

## Report a vulnerability

Report a security vulnerability privately, never in a public issue, pull request or discussion:

- **On GitHub:** the `tracebloc/cli` repository's **Security** tab, then **Report a vulnerability** ([open the form](https://github.com/tracebloc/cli/security/advisories/new)).
- **By email:** [security@tracebloc.io](mailto:security@tracebloc.io).

Tell us what is affected (repository, file, release or version), how to reproduce it, and what an attacker could do with it. If you know it is being exploited, say so in the first line.

## What happens next

- We confirm that we have your report within 2 working days.
- Within 7 days we tell you how we assess it: whether it is a vulnerability, and how severe it is.
- We fix it, release the fix and publish a security advisory. The advisory credits you, unless you ask us not to.
- Please wait 90 days, or until the fix is released if that comes first, before you disclose it. If it is being exploited, we agree a shorter time with you.

## What this covers

Everything tracebloc ships: the tracebloc CLI, the installer and the secure environment it sets up, the tracebloc SDK, the model zoo, the quickstart, and the platform and its dashboard at ai.tracebloc.io.

We do not run a bug bounty.
